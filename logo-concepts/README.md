# Showkasa logo concepts

Five SVG concept directions for a premium, cinematic, luxury-tech wordmark system.

## Concepts

1. **Concept 01, Editorial Space**
   - Wide tracking, calm luxury posture, restrained gold underline
   - Best if you want clean premium minimalism

2. **Concept 02, Split K**
   - Custom-built K creates uniqueness without getting gimmicky
   - Best if you want the wordmark itself to own the brand

3. **Concept 03, Framed Monogram**
   - Wordmark plus a small rounded frame icon
   - Best if you want a favicon/app-mark direction too

4. **Concept 04, Cinematic Contrast**
   - Light/heavy weight split between SHOW and KASA
   - Best if you want a more fashion-editorial feel

5. **Concept 05, Corner Frame**
   - Minimal frame corners with a clean wordmark
   - Best if you want a subtle interface-tech cue
